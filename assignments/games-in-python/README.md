
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Crie o clássico jogo da forca em Python para praticar manipulação de strings, listas, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Preparar a Palavra e o Progresso do Jogo

#### Descrição
Implemente a preparação de uma partida: escolha uma palavra aleatoriamente de uma lista predefinida e mostre ao jogador uma representação oculta da palavra.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir cada letra ainda não adivinhada como um sublinhado, mantendo as posições das letras visíveis conforme forem descobertas.
- Registrar as letras já tentadas e a quantidade de tentativas incorretas restantes.

### 🛠️ Conduzir a Partida até o Fim

#### Descrição
Permita que o jogador tente adivinhar letras até revelar a palavra ou ficar sem tentativas incorretas.

#### Requisitos
O programa concluído deve:

- Solicitar palpites de letras e atualizar o progresso após cada palpite.
- Diminuir as tentativas restantes quando o palpite não estiver na palavra.
- Encerrar a partida quando a palavra for adivinhada ou as tentativas incorretas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
